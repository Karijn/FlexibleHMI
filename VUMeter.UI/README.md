# VU meter add-in

Add a **VU Meter** to display numeric properties as needle angles. Select it in the document tree to configure its inputs, needle colors, and manual or property-controlled legend in the details panel. The main view shows the meter, peak indicators, and legend.

The **XY Control** and **Oscilloscope** show their plots and clear actions in the main view. Select one in the document tree to configure its axes or timebase, legend, properties, and points or channels in the details panel. The oscilloscope samples on the UI thread, so fast signals can be missed.

Add an **LED Bar VU Meter** from the **VU Meters** group. Configure the number of columns and bars per column and the shared finite minimum and maximum (defaults: one column, 10 bars, 0 to 100). Select a column by its 1-based number and choose its Integer or Double property; each column can use a different property. Reducing the number of columns retains hidden assignments for later. Existing documents that used a shared property keep it on their existing columns. Values outside the range are clamped for display. Missing, incompatible, and non-finite properties leave the affected column unlit; selecting that column shows its status. Property updates do not change document configuration.

Set **Lit rows around level** to zero to light every bar from the bottom to the current level. A positive value displays a centered band of that many bars, shifted inside the column at the ends; for an even count, the extra bar is above the current level. No bars light at or below minimum. Set the fade duration in milliseconds to animate each bar on and off, or zero for an immediate change.

Choose a base color and add color stops to apply colors from specified heights across every column. Use the picker beside each stop to choose its color. Heights can be entered as a percentage (0 to 100), a bar position (0 at the bottom, up to the number of bars), or a property value between the minimum and maximum. Fractional bar positions are supported. Switching height units converts existing stops to preserve their visual position. A stop changes its bar's color at its upper threshold. Enable **Interpolate colors (gradient)** to blend between stops; otherwise each stop's color applies until the next stop. Off bars remain dark green. When bounds or bar count change, stops outside the new range are displayed at the nearest edge until edited. Duplicate heights use the last listed stop.

The column and bar counts must be positive 32-bit integers. When there is insufficient screen space to draw every column or bar individually, columns and rows are combined visually; the configured counts and thresholds remain unchanged. All settings are saved with the document; existing single-column meters retain their original green appearance.
